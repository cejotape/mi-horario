# Mi Horario · Curso 2026/27

Horario semanal de clases + calendario de entregas, en un único archivo HTML sin dependencias.

- **Horario semanal** por cuatrimestre, con dificultad por asignatura y el día actual resaltado.
- **Calendario** de entregas/eventos y lista de "próximas", guardados en el navegador (`localStorage`).
- Instalable en el móvil como acceso directo (manifest + iconos).

Abrir: simplemente abre `index.html` en el navegador, o visita la versión publicada en GitHub Pages.
